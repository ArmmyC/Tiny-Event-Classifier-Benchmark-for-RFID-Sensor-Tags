# Feature Spec: RTL VCD Toggle Activity Summary

## Goal

Add an RTL switching-activity proxy flow for the existing baseline detectors.

The repo now has baseline RTL modules, optional simulation, optional synthesis, `rtl-report`, and research-report integration. The next missing hardware-facing metric is switching activity. This task adds VCD generation and a lightweight parser so the project can compare baseline detector activity using simulation traces.

This is still not silicon power. It is only a simulation toggle proxy.

## Required work

1. Update `rtl/tb/tb_baseline_detector.sv` so it can optionally dump VCD traces.
2. Add script support so each baseline simulation can write:

```text
results/rtl/vcd_threshold.vcd
results/rtl/vcd_fsm.vcd
results/rtl/vcd_lut_like.vcd
```

3. Keep current simulation pass/fail behavior.
4. Add a Python parser:

```text
python/tinysnnrfid/summarize_vcd_activity.py
python/summarize_vcd_activity.py
```

5. Add Makefile target:

```makefile
rtl-activity:
	python python/summarize_vcd_activity.py
```

6. The parser must tolerate missing VCD files and still write outputs.
7. Write generated outputs:

```text
results/rtl/rtl_activity_summary.json
results/rtl/rtl_activity_report.md
```

8. Update `python/tinysnnrfid/summarize_rtl_results.py` so `rtl-report` includes VCD activity summary if present.
9. Update `python/tinysnnrfid/build_research_report.py` so `make research-report` includes activity proxy context from RTL summary if available.
10. Update README with the new command.
11. Update `make clean` if needed.
12. Add tests that do not require Icarus Verilog or Yosys.

## VCD parser behavior

The parser should be simple and dependency-free.

It should count value changes per signal where possible. It does not need a full VCD simulator.

Minimum summary per baseline:

```json
{
  "found": true,
  "status": "available",
  "signal_count": 42,
  "total_toggles": 1234,
  "top_toggled_signals": [
    {"signal": "sample_bits", "toggles": 120}
  ]
}
```

If a VCD is missing:

```json
{"found": false, "status": "missing"}
```

## Testbench VCD behavior

Prefer plusargs so VCD output is optional:

```systemverilog
if ($value$plusargs("VCD_FILE=%s", vcd_file)) begin
    $dumpfile(vcd_file);
    $dumpvars(0, tb_baseline_detector);
end
```

The simulation script should pass a unique VCD path for each detector.

## Report sections

`rtl_activity_report.md` should include:

```text
# RTL Toggle Activity Report
## Inputs Found
## Toggle Summary
## Highest Toggle Signals
## Notes and Limitations
```

The report must clearly state:

```text
Toggle counts are simulation activity proxies and are not measured silicon power.
```

## Integration with rtl-report

`rtl_report.md` should include an activity section when `rtl_activity_summary.json` exists.

Suggested section:

```text
## Toggle Activity Summary
```

Include total toggles per baseline and the lowest-toggle baseline if available.

## Tests

Add tests for:

1. Missing VCD files produce missing statuses.
2. A tiny synthetic VCD is parsed and toggle counts are nonzero.
3. Activity JSON and Markdown reports are written.
4. `rtl-report` includes activity summary when `rtl_activity_summary.json` exists.
5. Research report includes RTL activity context when present.
6. Scripts still skip cleanly when RTL tools are missing.
7. `make test` works without RTL tools.

## Constraints

- Do not implement `tiny_snn_v2` RTL.
- Do not add heavy dependencies.
- Do not require RTL tools for normal tests.
- Do not claim measured silicon power or energy.
- Keep generated outputs out of git.
- Keep existing workflows working.

## Manual workflow

Run:

```bash
make rtl-vectors
make rtl-sim
make rtl-activity
make rtl-report
make research-report
```

If RTL tools are missing, `make rtl-activity` should still write a missing-input report.

## Definition of done

This task is complete when:

- VCD traces can be generated by the RTL simulation flow when tools are available.
- `make rtl-activity` writes JSON and Markdown outputs.
- `make rtl-report` includes activity evidence when available.
- `make research-report` includes RTL activity context when available.
- Tests cover missing inputs and synthetic VCD parsing.
- Existing workflows remain usable.
- No generated outputs are committed.
